# Harvey Extension Setup Guide

I got you 👍
You just need to download the Harvey ZIP file and load it as an unpacked extension using Chrome Developer Tools.

### Steps to Install

1. Download the Harvey `.zip` file.
2. Extract/unzip the folder.
3. Open Chrome and go to:
   `chrome://extensions/`
4. Turn on **Developer Mode** (top-right corner).
5. Click **Load unpacked**.
6. Select the extracted Harvey folder.

That’s it — the extension should now be active.
